# Security Policy

## Supported versions

Only the latest `main` is supported. There are no release branches or backports.

## Reporting a vulnerability

Please report security issues privately, not through public issues.

Use GitHub Security Advisories: open the **Security** tab of this repository and
choose **Report a vulnerability**. Include enough detail to reproduce the problem
and, if possible, a suggested fix.

You can expect an acknowledgement within a few days. This is a spare-time hobby
project, so please allow some time for a fix.
